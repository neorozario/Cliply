# 📋 Cliply

**Cliply** is a lightweight, browser-based clipboard and pinboard hybrid that allows users to paste text, images (like screenshots), and organize them in a visual layout. It’s perfect for quickly saving snippets, notes, or visuals—all in one place.

## ✨ Features

- 📌 Paste and pin text or images directly (Ctrl+V)
- 🖼️ Automatic rendering of screenshots and visuals
- 📝 Editable sticky-note style text blocks
- 📋 One-click copy back to clipboard
- 💾 (Coming Soon) Save and sync using localStorage or Firebase
- 🔄 (Coming Soon) Drag-and-drop positioning

## 🚀 Tech Stack

- HTML, CSS, JavaScript
- [Optional] TailwindCSS (for styling)
- [Optional] Firebase (for cloud sync - planned)

## 📦 Installation

```bash
git clone https://github.com/neorozario/Cliply.git
cd Cliply
open index.html in your browser
```
